# GDG on Campus CIC — Student Leaderboard

مشروع منفصل تمامًا عن الأدمن پورتال — ليدربورد حي للطلبة، الصفحة الرئيسية **عامة بدون تسجيل دخول** عشان أي طالب يفتحها من موبايله، والإدارة (إضافة تراكات/طلاب/نقط) من `/login`.

---

## 1) التجهيز الأول

فك الـ zip، افتحه في الـ IDE، وفي الـ Terminal:
```
npm install
```

---

## 2) عمل مشروع Supabase

هتحتاج **مشروع Supabase جديد ومنفصل** عن اللي عملته للأدمن پورتال (مش هيتشارك معاه، عشان دول مشروعين مختلفين تمامًا).

1. https://supabase.com → **New Project** → اختار اسم وباسورد وRegion.
2. **SQL Editor → New query** → افتح ملف `supabase/schema.sql`، انسخ كل محتواه، الصقه، ودوس **Run**.
3. **Authentication → Providers → Email** → اقفل **Allow new users to sign up**.
4. **Authentication → Users → Add user** → حط إيميلك وباسورد، وفعّل **Auto Confirm User**. ده هو حساب الأدمن بتاعك (تقدر تعمل أكتر من حساب بنفس الطريقة لو حابب تشارك الصلاحية مع حد تاني في التيم).
5. **Project Settings → API** → هات:
   - **Project URL**
   - **anon public** key

### جهّز `.env.local`
اعمل نسخة من `.env.local.example` باسم `.env.local` واملأها:
```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```
(مفيش Service Role Key المرة دي — المشروع ده أبسط ومش محتاجه).

---

## 3) تشغيل محلي

```
npm run dev
```
- الصفحة الرئيسية `http://localhost:3000` = الليدربورد العام (تقدر تفتحها من غير Login)
- `http://localhost:3000/login` = دخول الأدمن

من صفحة **Tracks** ضيف التراكات (وحدد لون لكل واحد)، وبعدين من **Students & Points** اختار التراك وضيف الطلبة وابدأ توزع نقط.

---

## 4) الرفع ببلاش على Vercel

نفس خطوات المشروع التاني بالظبط:
```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```
بعدين من https://vercel.com → **Add New Project** → اختار الـ Repo → قبل الـ Deploy ضيف الـ 2 Environment Variables (`NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`) → **Deploy**.

هتاخد لينك زي `gdg-leaderboard.vercel.app` — ده اللي تبعته للطلبة عشان يفتحوا الليدربورد من موبايلاتهم.

---

## 5) إزاي بيشتغل

- **صفحة الليدربورد العامة**: فيها زرار "All Tracks" (Top 50)، زرار لكل تراك (Top 30)، وزرار "This Week" (أكتر الطلبة كسبًا آخر 7 أيام). ميداليات 🥇🥈🥉، وبتحدّث نفسها أوتوماتيك كل 20 ثانية.
- **إضافة نقط**: من صفحة Students & Points، تحت كل طالب فيه 4 أزرار (Assignment / Quiz / Attendance / Bonus). تدوس على أي واحد، تختار رقم جاهز أو تكتب رقم مخصص، وتقدر تسيب ملاحظة.
- **تصحيح غلطة**: فورًا بعد أي نقطة، هيظهرلك Toast تحت الشاشة فيه "Undo" لمدة 6 ثواني. أو من أيقونة الـ History (🕐) جنب أي طالب تقدر تمسح أي حركة قديمة.
- **الأمان**: أي حد يعرف اللينك يشوف الأسماء والنقط بس. الملاحظات الداخلية متاحة للأدمن بس بعد تسجيل الدخول.

- ستايل بروفيشنال جديد: Gradient على العنوان، توهج (Glow) حوالين كروت التوب 3، حركة Hover على كل صف وكل زرار، انتقالات سلسة، Progress bars متحركة.

## 7) ربط اختياري بمشروع الأدمن پورتال التاني

المشروعين منفصلين تمامًا (Databases مختلفة)، فمفيش ربط تلقائي جاهز من نفسه. عملتلك **جسر (Bridge) اختياري** بسيط: Endpoint في المشروع ده اسمه `/api/award-points` يقدر أي نظام تاني (زي المشروع الأول، أو أي أداة automation) ينده عليه ويدي نقط لطالب — من غير ما يحتاج تسجيل دخول، بس محمي بكلمة سر مشتركة.

### تفعيله (اختياري، لو حبيت):
1. في `.env.local` (ومتغيرات البيئة في Vercel) ضيف:
   ```
   SUPABASE_SERVICE_ROLE_KEY=... (من Project Settings → API → service_role)
   WEBHOOK_SECRET=اي-كلمة-سر-طويلة-وعشوائية
   ```
2. أي نظام يقدر ينده الـ Endpoint بالشكل ده:
   ```
   POST https://your-leaderboard.vercel.app/api/award-points
   Content-Type: application/json

   {
     "secret": "نفس-الكلمة-اللي-حطيتها",
     "email": "student@example.com",
     "points": 5,
     "category": "attendance_bonus",
     "note": "Attended session 3"
   }
   ```
   لازم يبقى إيميل الطالب متسجل هنا بالظبط زي ما هو في المشروع التاني (نفس الإيميل).
3. لو حبيت فعلاً نربط سيشن HR بيقفلها في المشروع الأول بحيث تبعت النداء ده تلقائي، ده شغل إضافي في كود المشروع الأول (نضيف فيه `fetch` بسيط بعد ما HR يعمل Complete Session) — قولّي لو عاوز نعمله وهنروح نعدل في المشروع التاني.

لو مش هتستخدم الميزة دي، تجاهل القسم ده بالكامل — الـ Endpoint بيقفل نفسه تلقائيًا لو الـ `WEBHOOK_SECRET` مش موجود.

## 9) تحديث: تفاعل وحماس (Search + Podium + Animations)

بعد `npm install` (فيه مكتبة جديدة: `framer-motion` للحركات السلسة)، دول الإضافات:

| الميزة | فين تلاقيها |
|---|---|
| Search Box | فوق الليدربورد العام مباشرة — يدور في كل الطلبة (مش بس الظاهرين) ويوريك رانكك الحقيقي حتى لو برا الـ Top N |
| Podium (منصة التتويج) | بس في وضع الـ Display (`/display`) — الأول في النص وأعلى حاجة، التاني شمال، التالت يمين |
| Number Count-Up | أي رقم نقط بيتغير بيتحرك بعداد صاعد بدل ما يقفز فجأة |
| توهج نابض للأول بس | حلقة ضوء بتنبض حوالين صاحب المركز الأول تحديدًا (مختلفة عن توهج التاني والتالت) |
| 🔥 Rising Star of the Week | Widget فوق الليدربورد العام، بيوري مين كسب أكتر نقط الأسبوع ده من غير ما يكون في التوب 3 بتاع تراكه |
| Animated Reordering | لما الترتيب يتغير، الصفوف بتتحرك لمكانها الجديد بحركة سلسة بدل الاختفاء والظهور المفاجئ |
| "You Moved Up!" | في صفحة الطالب الشخصية — لو رانكه اتحسن من آخر زيارة، تظهرله رسالة احتفالية |
| احتفال أكبر عند تغيّر الـ #1 | Confetti أقوى (مدفعين من الاتجاهين + Burst في النص) لما صاحب المركز الأول نفسه يتغيّر — من غير صوت خالص |
| احتفال الإنجاز الشخصي | في صفحة الطالب، أول ما يعدي 100 أو 500 نقطة، يشوف احتفال مرة واحدة بس |
